# AI-Assisted Feature Engineering Demo

This demo shows how AI can help create a feature engineering pipeline without writing code.

We will follow two steps:
1. Use the Claude plugin Superpowers to create a plan.
2. Use CoCo (Cortex Code) to generate the pipeline in Snowflake.

What you need:
- Setup instructions are in [Demo-Prep-Instructions 1.md](Demo-Prep-Instructions%201.md)

Use case:
- Retail customer predictive analytics. 
- Build an extensive feature engineering pipeline for customer-level models such as churn, lifetime value, and segmentation

Notes:
- The data is spread across multiple tables, so the workflow focuses on feature engineering only.
- This demo does not cover feature selection or model training.
